Engineering Core Capabilities

Designed to address the 48-hour PLM Hackathon challenge for Tier-1 automotive electrification teams.

📊

Interactive Power BI Dashboard

Dynamic sidebar slicers for Material, Maturity, and Mass thresholds. Features Plotly Sunburst drill-downs, material distribution bars, and top-10 mass Pareto drivers.

🌳

Multi-Level BOM Product Explorer

Hierarchical tree navigation mapping subassemblies to leaf components. Includes CAD metadata inspector showing PLM IDs, revisions, organizations, and recursive assembly mass rollups.

🔄

Change Impact Analysis (Where-Used)

Bottom-up BFS graph traversal detecting all upstream parent assemblies affected when modifying a leaf component. Computes projected system weight deltas in real-time.

⚠️

Risk & Compliance Intelligence

Instant auditing of unassigned material properties (REACH/RoHS compliance risk) and lifecycle freeze alerts (100% of components currently in IN_WORK state).

🤖

Native PLM AI Assistant (100% Offline)

Autonomous engineering assistant providing instant technical answers grounded strictly in your BOM data. Cites verified PLM IDs for every component with zero external API dependencies.

⚡

High-Performance SQLite Engine

In-memory relational schema with B-Tree indexes on foreign keys, parsing 2,500+ lines of 3DEXPERIENCE XPDMXML into indexed tables in under 150 milliseconds.

System Architecture

End-to-end data pipeline from 3DEXPERIENCE XML extraction to interactive executive dashboard.

1

Raw XML Ingestion

Parses XPDMXML_ECAR_PLM.xml using plm_parser.py, extracting <Product> and <ProductInst> elements.

2

Relational In-Memory Index

Normalizes entities into SQLite with B-tree indexed foreign keys for sub-millisecond parent-child lookups.

3

Graph & Mass Engine

plm_logic.py computes recursive BOM depth-first traversal, bottom-up BFS Where-Used impact propagation, and mass rollups.

4

Streamlit & AI UI

Power BI-style unified dashboard in app.py with 5 interactive tabs, Plotly charts, and offline PLM AI assistant.
